# Estudo-sobre-Modelos-de-Regressão-para-Dados-de-Contagem
Este repositório contém os códigos em R utilizados nas aplicações apresentadas no trabalho de conclusão de curso: Estudo sobre Modelos de Regressão para Dados de Contagem.

Os scripts das aplicações estão organizados no diretório `Aplicações`. Já o diretório `Gráficos` contém uma função para a construção dos gráficos de diagnóstico dos modelos GAMLSS, com alguns ajuste, além de um exemplo de uso da função com os dados utilizados na Aplicação 2 do trabalho.
